# 경제·비즈니스 블로그 키워드 생성기 (무료 소스 전용)

미국 증시 핫 종목·뉴스와 한국 거시 이슈에서 **오늘 쓸 만한 블로그 키워드**를 뽑아, 글 유형·제안 주제·참고 기사 링크까지 붙여 줍니다.
API 키와 유료 서비스가 필요 없습니다. 에이전트 없이 Python 스크립트 하나로 돕니다.

## 빠른 시작
```bash
pip install -r requirements.txt
python -m keyword_maker --demo     # 모의 데이터로 동작 확인 (네트워크 불필요)
python -m keyword_maker            # 실제 수집 (인터넷 필요, 3~6분)
```
결과는 `output/<날짜>/`에 저장됩니다.

| 파일 | 용도 |
|---|---|
| `keywords.html` | 브라우저로 열어 보기. 키워드 옆 **복사** 버튼 |
| `keywords.md` | 키워드별 지표·기사 링크가 정리된 문서 |
| `keywords.csv` | 엑셀용(한글 깨짐 방지 인코딩) |
| `workflow_input.json` | content-company 워크플로우의 "주제·키워드 입력" 단계에 넣는 형식 |

`--demo` 결과는 폴더명에 `demo_`가 붙고 문서마다 DEMO 경고가 표시됩니다. 가짜 데이터이니 글에 쓰지 마세요.

## 옵션
`--top 15` 출력 종목 수 · `--no-trends` · `--no-youtube` · `--out 폴더` · `-v` 진행 로그

## 동작 방식
1. **후보 수집** — Yahoo 트렌딩, 급등·급락·거래량 상위, 관심종목(`config.py`의 `watchlist`) 최대 40개
2. **뉴스·신호 수집** — Yahoo Finance 뉴스 + Google News RSS(최근 48시간), SEC 8-K 공시, Reddit 인기글 언급
3. **1차 점수** — 기사 수·매체 수·등락폭·거래량 배율·트렌딩·Reddit·공시·한국 투자자 관심도
4. **심층 조회(상위 15개만)** — Google Trends 상승세(최근 48시간 ÷ 직전 5일), YouTube 최근 영상 수·조회수
5. **최종 점수와 키워드** — 헤드라인으로 이벤트(실적/규제/인수/계약/구조조정/신제품/급등·급락) 판별 → 한국어 키워드·글 유형·주제 생성, 네이버 자동완성으로 연관 검색어 확장
6. **거시·상시 키워드** — 금리·환율·연말정산 등 시드(`macro_seeds`)를 한국 뉴스량과 Google Trends(KR)로 점수화

점수는 후보군 안에서의 **상대 순위(0~100)** 입니다. 절대적인 검색량이 아니니 순위 참고용으로 쓰세요.

## 매일 자동 실행 (GitHub Actions, 무료)
이 폴더를 저장소에 올리면 `.github/workflows/daily.yml`이 한국시간 화~토 06:30에 실행하고 `output/`에 결과를 커밋합니다.
Actions 탭에서 수동 실행도 가능합니다. 저장소가 비공개여도 무료 한도 안에서 충분합니다.

## 설정 (`keyword_maker/config.py`)
- `watchlist`: 항상 후보에 넣을 종목
- `weights`: 점수 가중치 (어떤 신호를 더 중시할지)
- `macro_seeds`: 거시·상시 키워드 시드
- `edgar_user_agent`: **본인 이메일로 바꿔 주세요.** SEC가 연락처가 든 User-Agent를 요구합니다.
- `kr_names.py`: 티커 → 한글 종목명. 없는 종목은 영문명으로 나오니 자주 나오는 것부터 추가하세요.

## 알아둘 점
- 모든 소스는 **비공식 무료 경로**라 형식 변경이나 요청 제한(특히 Google Trends)으로 일부가 실패할 수 있습니다. 실패한 소스는 건너뛰고 나머지로 계속하며, 결과 문서 상단에 경고로 표시됩니다. Trends가 자주 막히면 `config.py`의 `sleep`을 늘리거나 `--no-trends`를 쓰세요.
- 인스타그램은 로그인·차단 문제로 안정적인 무료 수집이 어려워 제외했습니다.
- 한국어 월간 검색량 같은 정확한 수치는 무료로 얻을 수 없어 상대 관심도로 대체했습니다.
- 8-K 피드에서 Item 2.02(실적) 표기가 비어 있으면 실적 판별은 헤드라인에 의존합니다.
- 제안 주제와 기사 제목은 **초안**입니다. 글에 들어가는 수치·사실은 기존 3단계 검증(사실·계산·해석)을 거쳐야 합니다.
